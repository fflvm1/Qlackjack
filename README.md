# Welcome to Qlackjack (mobile branch)!
Qlackjack is a lightweight Qt-based copy of the known casino game, without the gambling touch.

## Features
### Flexible AI
If you don't like the traditional Blackjack rules, this game is going to be a soft spot for you!
**Qlackjack allows you to change the AI's behaviour to 1 of 4 different presets:**
1. **Default** (dealer hits everytime until total value is bigger than 16)
2. **Always hit**
3. **Always stand**
4. **Random** (1/2 chance of the dealer hitting)

To change the AI Presets, go to the **Settings** tab.

<img width="342" height="763" alt="image" src="https://github.com/user-attachments/assets/9e8607ea-8a7c-43fb-8c6c-2ccdd52efb42" />

### Customisation
**You can change the name of the player/dealer to whatever you want!**

To do that, go to the **Settings** tab.

If you want something more interesting, **you can also change the wallpaper and the back card design to 1 of 3 available options
or use a custom picture instead!**

For that, simply go to **Customisation** tab.

<img width="343" height="764" alt="image" src="https://github.com/user-attachments/assets/ee2dfa4c-56cf-4066-ad71-a88c1be277f3" />

### Statistics
**Qlackjack also tracks the amount of games you won and lost and lets you view your win rate!**

To check your stats, go to the **Stats** tab.

### Core gameplay
I thought that it was obvious, so i saved this for last, but of course, **the core hitting and standing mechanics are all present.**

## Fun back-story
When i just began learning C++, Blackjack was one of the first apps/games i ever made myself. I just liked the simplicity of that game,
and since it's quite easy to make something like this CLI-friendly, it was a perfect project.
I did eventually decide to add a GUI to it, so i made a Qt version of that, but i have since lost that project, so i decided to remake it.
